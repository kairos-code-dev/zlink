# ZLink Framework

실시간 메시징이 중요한 서버 시스템을 여러 프로세스로 나눠 만드는 프레임워크다.
서버 간 typed 메시징, 상태 단위(SPOT)의 직렬 실행, 외부 client 실시간 연결, 무중단
이전을 한 선언 모델 위에서 조합한다.

이 사이트는 **Phase 0 스파이크** 상태다. 탭과 스니펫이 동작하는지 확인하는 페이지만 있다.

- [스파이크 — 탭·스니펫 확인](spike.md)

Core 메시징 엔진 문서는 [core.zlink.systems](https://core.zlink.systems/)가 소유한다.
