I1 finding

F-I1-01 HIGH — Logical Multicast NODROP가 remote target 전체에 원자적이지 않다.
- spec: core/doc/spec/core/service/01-mesh-node.ko.md:380-387
- source: core/src/runtime/services/mesh/mesh_wire.cpp:1911-1929, core/src/api/mesh/mesh_messaging_api.cpp:843-853
- evidence: remote target을 순차 send하고, 중간 실패 전에 성공한 target은 되돌리지 않은 채 BACKPRESSURED를 반환한다. 주석도 이미 전달된 target을 retry하지 않는다고 명시한다. all-or-none 계약과 반대다.
- fix: 모든 remote pipe에 대해 실제 capacity reservation을 먼저 획득한 뒤 일괄 commit하거나, 동등한 2-phase wire protocol을 구현한다. 2개 이상 remote target 중 하나만 backpressure인 test에서 모든 target의 zero delivery를 검증한다.

F-I1-02 HIGH — Spot logical lifecycle과 Spot timer generation/serialization이 구현되지 않았다.
- spec: core/doc/spec/core/service/03-spot.ko.md:53-54,86-89,262-274
- source: core/src/api/mesh/mesh_api.cpp:222-239, core/src/api/mesh/mesh_node_api.cpp:85-101,969-992, core/src/api/mesh/mesh_node_api.cpp:398-410
- evidence: spot_timer_new은 generic timer를 만들고 timer_count만 증가시킨다. destroy hook, generation gate, application claim과의 상호배제 경로가 없다. timer_count 감소와 spots.erase 호출도 scoped no-hit다. 마지막 facade가 사라져도 logical Spot/owner가 남고, generic timer destroy 뒤에도 node destroy는 live_timers 때문에 영구 EBUSY가 될 수 있다.
- fix: Spot-aware timer ownership/release hook과 generation gate를 lifecycle coordinator에 넣고, timer handler와 application turn을 같은 serialization domain에서 실행한다. 마지막 참조 해제 시 Spot/owner를 제거하고 같은 RID 재생성 시 generation을 증가시킨다.

F-I1-03 HIGH — local Actor destroy가 deadline drain 없이 즉시 storage를 제거하고 OK completion을 만든다.
- spec: core/doc/spec/core/service/04-actor.ko.md:181-182
- source: core/src/api/mesh/mesh_actor_api.cpp:609-668
- evidence: draining=true 직후 owner와 actor를 erase하고 operation을 즉시 OK로 complete한다. timeout_ms를 drain 대기에 사용하지 않으며 active application claim, request completion, bound session control을 확인하지 않는다.
- fix: Actor lifecycle coordinator가 새 admission을 닫고 세 drain 조건을 deadline까지 기다리게 한다. held claim, pending request completion, bound session control 각각의 성공/timeout test를 추가한다.

F-I1-04 HIGH — shutdown deadline에서 timeout_ms==0 operation이 terminal completion 없이 남는다.
- spec: core/doc/spec/core/service/01-mesh-node.ko.md:166-174,306-308
- source: core/src/api/mesh/mesh_node_api.cpp:308-383, core/src/api/mesh/mesh_node_api.cpp:64-78, core/src/api/mesh/mesh_messaging_api.cpp:925-936
- evidence: timeout 0 operation은 timeout task를 만들지 않는다. shutdown은 operations가 남으면 deadline에 claim만 revoke하고 TIMED_OUT을 반환하며 operation을 종료하지 않는다. node는 DRAINING에 남고 재호출은 EDEADLK다. 따라서 shutdown terminal 경로가 없고 destroy 전까지 무기한 잔류할 수 있다.
- fix: shutdown deadline에서 outstanding operation을 원자적으로 detach하여 exactly-once ESHUTDOWN completion으로 만들고 reply route를 정리한다. timeout 0 request를 미응답 상태로 둔 shutdown test를 추가한다.

F-I1-05 MEDIUM — inbound-first peer와 manual endpoint의 MIXED 병합이 도달하지 않는다.
- spec: core/doc/spec/core/service/01-mesh-node.ko.md:229-251
- source: core/src/runtime/services/mesh/mesh_wire.cpp:498-577, core/src/api/mesh/mesh_node_api.cpp:475-484
- evidence: inbound HELLO로 만든 DISCOVERY peer에는 endpoint를 기록하지 않는다. manual connect는 endpoint 문자열의 정확한 일치로만 MIXED로 바꾼다. 따라서 manifest가 지적한 inbound endpoint 공백과 manual endpoint 불일치 경로는 별도 intent를 만든다.
- fix: inbound connection의 관측 remote endpoint를 peer identity에 안정적으로 기록하고, source ownership을 하나의 intent에 병합한다. inbound admission 후 같은 endpoint의 manual intent를 추가/제거하는 실제 transport test를 만든다.

F-I1-06 MEDIUM — higher-generation peer 교체가 DRAINING 상태를 만들지 않는다.
- spec: core/doc/spec/core/service/01-mesh-node.ko.md:246-254,100-120

F-I1-07 MEDIUM — versioned array output의 선검증/no-partial-output 계약을 위반한다.

F-I1-08 MEDIUM — 공개 문자열 UTF-8 검증이 누락되거나 strict scalar validation이 아니다.
