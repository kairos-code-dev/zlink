# Node.js Routing ID 자동 할당 interface 이동 안내

Routing ID 자동 할당의 정확한 public TypeScript declaration은
[Routing ID 자동 할당](interfaces/09-routing-id-allocation.ko.md)이 소유한다. Node.js 공개 interface의
전체 문서 목록은 [공개 인터페이스 목차](interfaces/README.ko.md)에서 확인한다.

이 파일은 이 문서 주소를 사용하는 링크를 새 문서로 연결하기 위한 안내 문서이며 declaration을
중복해서 정의하지 않는다.
