# 관측성·운영 표면 확장 초안 (Draft)

> **상태: DRAFT.** 이 디렉토리의 문서는 아직 채택된 공개 계약이 아니라 **제안 초안**이다.
> 리뷰 전에는 어떤 이름·필드·기본값도 하위호환 대상이 아니다.

이 초안들은 "프로덕션 게임 백엔드 프레임워크"로서 남은 관측성·운영 표면의 공백을 메우기 위한
제안이다. 세 문서 모두 framework의 기존 설계 철학 — **framework는 신호와 계약을 주고, 백엔드/
대시보드/배포 스크립트는 앱이 끼운다** — 을 그대로 따른다. 어디에도 특정 백엔드(OTel/Prometheus/
k8s)에 대한 하드 의존을 넣지 않는다.

## 문서

| 문서 | 무엇을 정하나 | 성격 |
|------|---------------|------|
| [런타임 메트릭 계기](runtime-metrics.ko.md) | SPOT 큐 깊이·CCU·actor 이동·RPC 지연 등 **밖에서 못 재는 신호**를 계기(counter/gauge/histogram)로 노출 | 새 표면 추가 |
| [Graceful Drain & Handoff 수명주기 계약](graceful-drain-handoff.ko.md) | stateful 노드가 우아하게 종료·핸드오프하는 순서를 **API + 상태 기계**로 정의(무중단 배포용) | 흩어진 메커니즘을 계약으로 묶기 |
| [메시지 흐름 상관관계 확장](flow-correlation-extensions.ko.md) | 기존 흐름 추적의 세 이음매(spot/actor 홉 관통, 전역 유일 flow-id, 언어별 완성) 마감 | 기존 추적의 가장자리 다듬기 |

## 기존 문서와의 관계

- [메시지 흐름 추적](../message-flow-tracing.ko.md) — 이미 채택된 per-message 추적 계약. 메트릭·
  흐름 확장 초안은 이 문서와 **짝**을 이룬다(추적=흐름 로그, 메트릭=집계 시계열).
- 세 초안이 리뷰를 통과하면 `draft/`에서 정식 공통 스펙 위치로 승격하고, 각 언어 문서·회귀
  매트릭스에 반영한다.
