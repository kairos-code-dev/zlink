# perf-refactor 2차

이 폴더는 `perf-refactor` 1차 완료 이후 수행한 후속 POSD 검토 문서를 모아둔 곳이다.

포함 범위:
- `core/perf` 후속 POSD 검토 문서
- 각 binding perf 디렉토리의 후속 POSD 검토 문서

문서 성격:
- 이미 완료된 1차 리팩토링을 재탕하지 않음
- `perf` 목적 범위 안에서만 후속 리팩토링 가치가 있는 항목을 정리
- `PERF_POLICY` 및 single/multi 정책 준수
- `core/perf`와 동일한 측정 의미 유지 전제

읽는 방법:
1. 먼저 [../1차/PROGRESS.md](../1차/PROGRESS.md) 와 1차 계획 문서로 현재 완료 상태를 확인
2. 그 다음 이 폴더의 `*-posd-followup-plan.ko.md` 로 후속 리팩토링 후보를 확인

현재 용도:
- 실제 다음 작업 선정용 후보 문서
- 유지보수-only 판단과 follow-up 가치가 있는 영역을 구분하는 기준 문서
