# TicTacToe

이 샘플은 C++ framework의 STREAM과 ActorGateway 기반 actor/session relay 흐름을
검토하기 위한 리뷰 샘플이다.

포함 범위는 아래와 같다.

- STREAM endpoint 구성
- ActorGateway attach
- Entry Spot 등록
- actor factory 등록
- session actor bind
- STREAM packet relay
- bound session push
- actor join/move 흐름
- disconnect cleanup

샘플 이름에는 별도 접미사를 붙이지 않는다. 이 샘플이 STREAM과 ActorGateway 기반
actor/session relay의 기준 샘플이다.
