# C++ Binding Perf Porting Plan

> 이 파일은 오래된 포팅 계획 본문을 정리한 자리다.
> 현재 `bindings/cpp/perf/` 구현과 실행 계약은 아래 문서를 단일 기준으로 따른다.
>
> - `bindings/cpp/perf/README.md`
> - `doc/perf/PERF_POLICY.md`
> - `doc/perf/PERF_SINGLE_TEST_POLICY.md`
> - `doc/perf/PERF_MULTI_TEST_POLICY.md`

예전 설계 메모에 남아 있던 삭제된 pattern, 비정책 metric, 옛 실행 흐름은
현재 기준으로 효력이 없다. 새 메모가 필요하면 현재 정책과 실제 코드 기준으로
별도 문서를 작성한다.
