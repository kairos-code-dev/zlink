# Service API

Core currently exposes SPOT service APIs only. Public Discovery and Registry C
APIs were removed from the core contract; applications and bindings must not
reintroduce those removed headers or function prefixes as current APIs.

Read [spot.md](spot.md) for SPOT publish/subscribe, route bridge, publisher,
actor, and direct routed messaging contracts.
