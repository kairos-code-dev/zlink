# 가이드 작성 스타일 규약

이 문서는 `doc/guide/`(코어 가이드 + 언어별 바인딩 가이드)를 작성·수정할 때 따르는
규약이다. 저장소 전체 규칙은 [AGENTS.md](../../AGENTS.md)가, 이 문서는 가이드에
한정한 구체 규약을 소유한다.

## 1. 디렉토리 역할 (어디에 무엇을)

| 디렉토리 | 독자 | 넣는 것 | 안 넣는 것 |
|----------|------|---------|-----------|
| `doc/guide/` | 라이브러리 사용자 | 의도·사용법·실전 예제 | 내부 구현 상세 |
| `doc/spec/` | 바인딩 개발자 | 공개 API 계약 | 사용 튜토리얼 |
| `doc/internals/` | core 유지보수자 | 내부 구조·프로토콜 | — |

guide에서 내부 동작을 참고해야 하면 **internals를 링크**한다. 사용자는 내부 소켓이나
inproc endpoint를 알 필요가 없다.

## 2. 황금률 — 개념은 한 번만 쓴다

같은 개념이 여러 문서에 중복되면 드리프트가 생긴다. 각 문서 레이어는 **자기
소유물만 쓰고 나머지는 링크**한다.

- **개념의 정식 정의**(왜 DEALER인지, SPOT이 무엇인지)는 **코어 가이드가 1번만**
  소유한다.
- **언어별 바인딩 가이드**는 그 언어의 사용법·타입 매핑·고유 규칙만 소유하고
  개념은 코어로 링크한다. 각 섹션은
  **[한 줄 방향 제시] + [코어 개념 링크] + [그 언어 관용 코드]** 형태다.
- "DEALER란?"을 바인딩 가이드에 다시 쓰지 않는다 — 항상 코어 03-3을 링크한다.

## 3. 챕터 템플릿

각 주제(소켓 패턴·기능) 문서는 일관된 흐름을 따른다.

```
개요(한 줄 정의 + 언제 쓰나) → 기본 사용법 → 옵션 → 사용 패턴 → 주의사항/더 보기
```

서비스·상위 기능 문서는 **역할(무엇) → 언제(결정 기준) → 사용 형태** 순서를 쓴다.
"기능 나열"이 아니라 "언제·왜"가 들어가야 가이드다.

## 4. 바인딩 가이드 문서 세트 (모든 언어 공통)

각 언어 가이드는 코어 가이드 Part 경계에 맞춘 6문서를 동일 파일명으로 가진다.

| 파일 | 내용 |
|------|------|
| `index` | 기능 지도 + 진입 안내 |
| `01-getting-started` | 설치 · 5분 예제 · 핵심 타입 · 소유권 |
| `02-messaging` | 소켓 패턴별 |
| `03-services` | Registry · Discovery · SpotNode·Spot · Actor |
| `04-operations` | 옵션 · TLS · 모니터링 · 폴러/타이머 · 스레딩 |
| `05-reference` | 에러 · 코덱 · C API↔언어 대응표 · API 레퍼런스 · 샘플 |

`03-services`는 모든 언어가 동일 프레이밍을 공유한다: 멘탈 모델 링크 +
"언제 서비스 레이어가 필요한가" 표 + "왜 Spot — 실행 직렬성" + "왜 Actor —
재접속 이전성".

## 5. 다이어그램 규약

- **적층(layer) 다이어그램은 ASCII**로 그린다(아키텍처 계층 등). `+---+` 박스.
- **흐름·시퀀스 다이어그램은 Mermaid**로 그린다(`flowchart`, `sequenceDiagram`).

## 6. 링크·경로 규칙

- 바인딩 가이드(`doc/guide/bindings/<lang>/`)에서 코어 챕터로 가는 링크는
  **`../../0X-...`** 깊이다(`../0X`는 잘못).
- 같은 언어 가이드 내부 링크는 `./0X-...`.
- 코어 가이드 간 링크는 `./0X-...`.
- 모든 문서는 `.md`/`.ko.md` 쌍으로 관리하고 상호 토글 링크를 머리에 둔다.

## 7. 예제 코드

- 예제는 **실제 공개 API에 맞아야** 한다 — 존재하지 않는 메서드를 지어내지 않는다.
  의심되면 해당 바인딩의 contract/소스를 확인한다.
- 값은 현실적인 production-like 값을 쓴다(포트·심볼·금액 등).
- 가능하면 `bindings/<lang>/samples/`의 실행되는 샘플과 1:1 대응시킨다([예제 추출
  규약](EXAMPLES.ko.md)).

## 8. 표기

- 코드 식별자·상수는 백틱(`` `zlink_send` ``).
- 강조는 **굵게**(과용 금지).
- 영문 고유명사(SPOT, Actor, ROUTER)는 그대로 두고 일반 용어는 한국어로 쓴다.
- 용어 첫 등장 시 [용어집](glossary.ko.md)으로 링크하거나 한 줄 정의를 붙인다.
