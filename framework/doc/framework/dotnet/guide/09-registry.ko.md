# 9. Registry

Core C API의 Discovery/Registry 표면은 제거되었다. 이 장은 예전 Registry 구동과 topology
조회 예제를 더 이상 정식 사용법으로 제공하지 않는다.

현재 guide 에서 바로 사용할 수 있는 서버 간 channel 연결은 역할 등록에 endpoint 를 직접
주는 방식이다. channel 이름만으로 endpoint 를 찾는 자동 연결은 location runtime 과
location store 설계가 정식 공개 계약으로 확정된 뒤 별도 문서에서 다룬다.
