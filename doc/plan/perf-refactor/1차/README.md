# perf-refactor 1차

이 폴더는 `perf-refactor`의 1차 정리 문서를 모아둔 곳이다.

포함 범위:
- 기존 언어별 POSD 리팩토링 계획 문서
- 진행 현황 문서 `PROGRESS.md`
- 감사/정합성 확인 문서

문서 성격:
- 1차 리팩토링의 목표, 완료 정의, 진행 결과, 감사 기록
- 실제 완료 여부와 문서 정합성은 이후 검토를 거쳐 최신화되었음
- 초기 감사본은 기록 보존 목적의 아카이브도 포함함

권장 읽는 순서:
1. [PROGRESS.md](/home/hep7/project/kairos/zlink/doc/plan/perf-refactor/1차/PROGRESS.md)
2. 각 언어별 `*-posd-refactor-plan.ko.md`
3. 감사 문서

참고:
- 후속 POSD 검토와 다음 단계 후보는 상위 디렉토리의 [2차](/home/hep7/project/kairos/zlink/doc/plan/perf-refactor/2차) 폴더에 정리되어 있다.
